# Upload to GitHub

Extract this ZIP and upload its contents to your repository. The complete built website is in `dist/`; `build.py` regenerates its HTML pages. All images, fonts and the three approved logos are included.

For static hosting, publish the `dist` directory. GitHub Pages requires a workflow that deploys `dist`, or copying the contents of `dist` to the Pages publishing folder.

The export excludes Git history and the original Sites hosting identity.
