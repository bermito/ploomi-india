# Ploomi Coffee — complete visual redesign R3

This is the complete GitHub-ready website, prepared 15 November 2026. It replaces the previous visual layout. No build or package installation is required.

## Upload to your existing GitHub website

1. Unzip the download on your device.
2. Upload the CONTENTS into your existing publishing folder. Keep index.html at the same level as assets/, experience.css, experience.js and styles.css. Do not upload only the ZIP, and do not nest everything inside an extra folder.
3. Include every folder and the new experience.css and experience.js files. Preserve your existing CNAME file and any required repository workflows.
4. Commit the files. If using GitHub Pages, confirm Settings > Pages is publishing the correct branch and folder. If GitHub is connected to a different hosting provider, use that provider's current deployment settings.
5. After deployment, the homepage should open with a deep-blue background, a large 'Good coffee. For your business.' headline and a photographic coffee-bar image. If the old pale café-illustration homepage appears, the new deployment is not what you are viewing.
