# Ploomi — ready for GitHub Pages

1. Extract this ZIP.
2. Upload all extracted files and folders directly to the root of your GitHub repository. `index.html`, `assets`, `coffees`, and `about` must be at the top level, not inside a `dist` or ZIP-named folder.
3. In repository Settings → Pages, select Deploy from a branch, your upload branch (usually main), and / (root). Save.
4. Open the published website URL shown in Pages after deployment completes. Uploading a ZIP alone does not publish its contents.

No build command is required. Keep all folder names unchanged. Pages, images, fonts and navigation use relative links, so repository-prefixed URLs work. The existing menu, approved logos and page content are preserved.

The previous ChatGPT hosting address has been removed from canonical and social URL metadata. Once your final website URL is known, set canonical URLs, the social image URL and a sitemap for that destination. This archive fixes hosting and navigation; it does not include the later proposed Kerala content changes.
